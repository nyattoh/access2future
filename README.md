# Access2Future

MS Accessで運用されている業務システムを、現場に合うシステムへ作り替えるためのアプリを目指すプロジェクトです。

## 構想

Accessファイルを取り込み、テーブルデータ・クエリ・フォーム・レポート・ページを自動解析し、移行先（Webアプリ、Excel、Googleスプレッドシート + GAS、その他）を選んだうえで、要件定義、grill-with-docs / Jevによる検討、実装、移行後の検証までを支援する構想です。

自動解析の対象範囲や対応できないAccessオブジェクト、移行先ごとの実現方法は未検証です。「ページ」が何を指すかも含め、技術範囲は今後明確にします。

## 提供の方向性

この一連の仕組みをOSSとして公開する方向を検討しています。自動の流れだけでは実装できないケースに対して、相談や実装支援を提供することも収益化の候補です。

具体的なOSSライセンス、機能範囲、支援内容、相談窓口、価格、提供形態は未定です。このリポジトリはまだLICENSEを含まず、ここに書かれた構想や公開状態だけでOSSライセンスが付与されるものではありません。

## 開発状況

アプリ機能はまだ実装されていません。現在は構想をまとめたREADMEとGit管理ファイルを用意した段階です。技術構成、対応範囲、提供条件は今後の検討で決めます。
